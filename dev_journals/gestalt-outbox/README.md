# Gestalt outbox

Notes written in this project that the gestalt plugin's own sessions should read: retros of process experiments, proposed rule or skill changes, and findings about how the process ran.

- One file per note, named `<date>-<topic>.md`
- A note proposes; it changes nothing. Robert makes every change to the plugin
- A note that gestalt has taken in can be deleted, or moved to `_archive/`
